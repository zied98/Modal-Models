🎬 Wan2.2 Video Studio

Génération de vidéos par intelligence artificielle
🎥 Modèle Wan2.2-T2V-A14B - Génère des vidéos 480P jusqu'à 10 secondes

📥 Comment récupérer votre vidéo

  1. Lancer le serveur de sauvegarde (si ce n'est pas déjà fait) :
    cd C:\Users\pc\Desktop\chatterbox_geopolitique\video_generation && python proxy_server.py
  2. Ouvrez un terminal dans le dossier video_generation/
  3. Listez les vidéos disponibles :
    python -m modal volume ls wan-outputs
  4. Identifiez votre vidéo (la plus récente avec la date du jour)
  5. Téléchargez-la :
    python -m modal volume get wan-outputs [NOM_FICHIER] generations/ma_video.mp4
  6. Ouvrez la vidéo dans generations/ avec votre lecteur

💡 Astuce : Créez d'abord le dossier generations avec mkdir generations

⚡ Premier appel : 2-3 min (chargement du modèle)
🚀 Générations suivantes : 5-10 min
💾 Les vidéos sont stockées sur le volume Modal wan-outputs
